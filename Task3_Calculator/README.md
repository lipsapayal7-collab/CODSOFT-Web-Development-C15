# Task 1 - Calculator

A responsive calculator built using HTML, CSS and JavaScript as part of the CODSOFT Web Development Internship.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Basic arithmetic operations
- Addition, subtraction, multiplication and division
- Percentage calculation
- Clear and delete buttons
- Error handling for invalid calculations
- Responsive design
- Light and dark theme
- Theme preference saved using localStorage
- Button hover and click effects

## Project Structure

- `index.html` - Calculator structure and buttons
- `style.css` - Calculator design, colors and responsive layout
- `script.js` - Calculator operations and theme functionality

## How to Use

1. Open `index.html` in a web browser.
2. Use the calculator buttons to enter values.
3. Press `=` to calculate the result.
4. Use `AC` to clear the display and `DEL` to remove the last value.
5. Use the theme button to switch between light and dark mode.
