# Task 2 - Landing Page

A responsive furniture store landing page developed using HTML, CSS and JavaScript as part of the CODSOFT Web Development Internship.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive furniture store design
- Modern hero landing section
- Furniture product showcase
- Product search functionality
- Category-based product filtering
- Add to Cart functionality
- Buy Now functionality
- Shopping cart with total price
- Login and delivery details form
- Checkout interface
- Cash on Delivery and Card payment UI
- Order confirmation message

## Project Structure

- `index.html` - Main webpage structure
- `style.css` - Page styling and responsive design
- `script.js` - Search, filtering, cart and checkout functionality
- `image/` - Furniture product images
